# Raw data

Run `python src/download_data.py` from the repository root. The script downloads HEMOBP Version 3 directly from Figshare and verifies these checksums:

| File | Size in bytes | MD5 |
| --- | ---: | --- |
| `idp.csv` | 35,151 | `31d269f59bf4acc719f392ad9164d08a` |
| `d1.csv` | 11,130,894 | `7db3b48bae2c73e3ecd731dbcd452233` |
| `vip.csv` | 262,851,369 | `ff1589610cf7aa3b3e01ba979b6bdc44` |

Source: HEMOBP Version 3, DOI [10.6084/m9.figshare.6260654.v3](https://doi.org/10.6084/m9.figshare.6260654.v3), CC BY 4.0.

The data are not tracked in Git.
